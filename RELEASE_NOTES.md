# Auto Swingshot v1.0.0

The first public release of **Auto Swingshot** for Ratchet & Clank 1 on OpenRAC.

Press Circle near a Versa-Target to automatically equip and fire the Swingshot, then return to your previous weapon without opening the weapon wheel.

## Features

- Automatic Swingshot usage with both swinging and pulling Versa-Targets
- Airborne chaining and previous-weapon restoration
- Tunable defaults calibrated in NTSC-U gameplay: **16 distance / 7 height / 30° facing**
- Optional diagnostic observation mode
- Windows x64, Linux x64/ARM64, macOS Intel/Apple Silicon and Android ARM64 native builds

## Installation

Open the **OpenRAC Launcher → Mods → Add from a link** and paste:

https://github.com/glawks/auto-swingshot

Alternatively, download a platform-specific archive or the combined `auto-swingshot-1.0.0.zip` below.

## Notes

- Tested in-game on **NTSC-U**. **PAL gameplay has not yet been verified.**
- Activation needs a **fresh Circle press**; holding Circle and entering range does not auto-switch.
- The base game controls hook attachment and release.
- Existing saved settings are retained on upgrade; choose **16 / 7 / 30°** if you previously customised them.
- Tested with several other quality-of-life mods simultaneously on NTSC-U, but not every possible mod combination.

Report any issues with the game version, mod list and game log on [GitHub Issues](https://github.com/glawks/auto-swingshot/issues).
